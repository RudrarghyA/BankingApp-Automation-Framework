# 🏦 BankingApp Automation Framework

### Overview
This project is a **Hybrid Selenium Automation Framework** designed for automating test scenarios of a **Banking Web Application**.  
It validates key modules such as Login and Account Overview using **Selenium WebDriver, TestNG, and Extent Reports**.

---

### ⚙️ Tech Stack
- **Programming Language:** Java  
- **Automation Tool:** Selenium WebDriver  
- **Testing Framework:** TestNG  
- **Build Tool:** Maven  
- **Reporting:** Extent Reports  
- **Design Pattern:** Page Object Model (POM)

---

### 🚀 Features
- Browser setup using WebDriverManager  
- Page Object Model for reusability  
- Explicit Waits for dynamic elements  
- Automated HTML reporting with Extent Reports  
- Easy-to-scale framework for multiple banking modules
